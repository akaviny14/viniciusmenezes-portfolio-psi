Context

Managing Power BI access meant manually updating permissions for every user, every dashboard, every change. New hires, departures, new dashboards — all handled manually in Power BI Online and tracked in a spreadsheet. Monthly, Security requested an audit log that required IT to extract it manually.

Action

I identified the opportunity during a feasibility study on embedding Power BI inside Desk Manager, proposed the architecture, and structured the datasets needed to support the automation. A developer implemented the code. The system identifies users via the platform’s own API, checks their dashboard permissions, fetches embed credentials dynamically, and renders each dashboard directly inside their workspace. Admins manage access through two dedicated screens. When the monthly Security ticket opens, a webhook triggers the automation that queries logs, generates the report, attaches it and closes the ticket automatically.

Result
~50 licences eliminated~R$4,000/month removed from the cost base
45 min → under 5 minaccess management, any operation
Instant audit reportwas a manual IT request every month
